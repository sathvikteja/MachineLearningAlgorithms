# Machine Learning Algorithms

This repository contains my **machine learning algorithm implementations** and notes,
organized as Jupyter notebooks.  
The goal is to understand ML algorithms conceptually and practically through hands-on
implementation.

- k-Nearest Neighbors (k-NN)
- Naive Bayes
- Decision Trees
- Support Vector Machines (SVM)
- k-Means Clustering
- Principal Component Analysis (PCA)
